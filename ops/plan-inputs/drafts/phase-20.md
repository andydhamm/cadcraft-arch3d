## Brief vs code, decided here

(1) Plan views are ArchModel records embedding a CADCraft LayerState (with the new wildcard rules) and a zoom restored through the named-view path; no VIEW/LAYERSTATE records are written per view (view.electrical still saves its 'Electrical' state, as phase 15 did). (2) The seven templates are implicit defaults: present in every drawing, not serialized until changed; deleting them sticks. (3) Floor Plan hides E-*, A-ROOF*, C-*, L-* and keeps A-CLNG (phase 16 draws soffits dashed and footings in floor plans); Reflected Ceiling, Roof Plan and Site hide A-ANNO-DIMS; the plan with no view open is unchanged prim for prim. (4) 'phase 16's tray room shows two tray outlines and the label 2.70': phase 16's nested pair (outlines 0.7..5.35 x 3.65..7.3 and 1.3..4.75 x 4.25..6.7, tray labels 2.70 and 2.85), and a 45-degree pitched tray (outline + top ring, label 2.70) as a second case; a room's own ceiling text is its base finished ceiling (2.40) and each tray top is labelled separately. (5) Pitches read x/12 in every unit system. (6) Dimensions are CADCraft DIMLINEAR/DIMALIGNED entities with AssocSnap::Arch {feature, along} on the arch proxy handle (CADCraft ASSOC xdata snap code 7 in DXF); AUDIT keeps them while the object exists. (7) Auto dims are model-space entities on A-ANNO-DIMS (style 'Arch'); a plan showing one level hides other levels' auto dims; manual dims stay level-less. (8) A row edited by hand is never regenerated, but its dimensions stay associative. (9) Driving does not re-detect rooms (no CADCraft edit does); the driving check runs roomdetect before reading the brief's areas. (10) Room label text uses 'm2' and ' x ' (stroke font). (11) The Electrical view's annotation layer E-ANNO-NOTE is created when it opens, so phase 15's unit test now counts 3 shown layers and 5 saved ones (dimmed stays 2); view.electrical still saves the layers from before the view (plus those the view creates), so the UI toggle still turns it off by restoring them (its acceptance check is unaffected). (12) No new arch object kind, so no handle offset is reserved in phase 20. (13) The roof plan draws eaves and rakes from the plane rings, not from roof.edges (gable edge data is not pinned by tests). (14) The plan is annotated at the shown level (plan_level), the level its walls are drawn at; a view's own level is used only to inspect it unopened. (15) In a reflected ceiling plan a room's label block keeps out of its trays, so a room's ceiling height never sits on a tray's height label. (16) Auto-dim rows sit on a fixed line per kind (openings 1.0, walls 1.5, overall 2.0 beyond the side's outer face) rather than packed by how many rows exist, and a kept row is updated in place, so a row that appears inside kept ones never shares their line.
